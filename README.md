# Site do Assistente Virtual para Clínicas

## Visão Geral
Este é um site responsivo para apresentar o sistema de assistente virtual para clínicas de saúde. O site foi projetado para demonstrar as funcionalidades e benefícios do sistema de forma clara e profissional.

## Características
- Design responsivo que funciona em dispositivos móveis e desktop
- Seções informativas sobre o sistema
- Demonstração interativa do funcionamento do assistente
- Formulário de contato funcional
- Animações e transições suaves

## Estrutura do Projeto
- `index.html`: Página principal com todas as seções
- `styles.css`: Estilos e design responsivo
- `script.js`: Funcionalidades interativas e comportamentos
- `README.md`: Documentação do projeto

## Como Usar
1. Abra o arquivo `index.html` em qualquer navegador moderno
2. Navegue pelas seções para conhecer o sistema
3. Interaja com o formulário de contato e a demonstração

## Funcionalidades Destacadas
- Demonstração do chat em tempo real
- Animações ao rolar a página
- Menu responsivo para dispositivos móveis
- Formulário de contato com validação
- Navegação suave entre seções

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript Vanilla
- Fonte Poppins (Google Fonts)
- Design responsivo com Grid e Flexbox
